# GrapheneOS setup

Only for [supported GrapheneOS devices](https://grapheneos.org/install/). Follow the official installation guide for the exact model.

1. Configure [Niagara](README.md#start-with-niagara) if desired.
2. For functions requiring Google Play services, use [sandboxed Google Play](https://grapheneos.org/usage#sandboxed-google-play) only when needed.
3. Verify notifications, calling, messaging, NFC and other required device functions before switching phones.

Do **not** use [Samsung cleanup](samsung_cleanup.md) package commands or disable GrapheneOS security controls to imitate Samsung settings.

Reference: [GrapheneOS usage guide](https://grapheneos.org/usage/).
