# App setup checks

Use these checks after following the [shared Android setup](README.md#shared-android-setup). This is a setup checklist, not a list of installed or recommended personal apps.

1. Install only applications needed for the device's intended use, preferably from trusted, official distribution sources.
2. Restore account data using each application's supported sign-in or migration procedure. Verify password-manager and authenticator access before retiring the previous device.
3. For applications that must receive calls, messages, notifications or other time-sensitive updates, verify notification permissions and background operation. On Samsung One UI, review battery restrictions as described in [Samsung One UI cleanup](samsung_cleanup.md#preserve-features-and-background-connectivity).
4. Test essential calling, messaging, security, connectivity and backup/restore functions. On GrapheneOS, also follow the [compatibility checks](grapheneos_setup.md#install-and-set-up).
5. In Niagara Launcher, verify favorites, widgets and shortcuts after installation or backup restoration.

Only add instructions for an application when a repeatable configuration step is actually needed. Keep personal app inventories, accounts and usage details out of this repository.
