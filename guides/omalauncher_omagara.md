# Omalauncher + Omagara

1. Install [Omalauncher](https://play.google.com/store/apps/details?id=dev.omalauncher).
2. Omalauncher → Store → Full-screen widgets → **Omagara** → **Install**.
3. Omalauncher → Settings → Style → Home page (`home.home-page`) → `0`.
4. Samsung → Settings → Apps → Choose default apps → Home app → **Omalauncher**.

The maintainer currently uses [Omagara](https://github.com/SimonSchubert/omarchy-widgets/tree/main/faces/dillacorn/omagara), a Niagara-inspired face they developed. Omagara is a good option if its missing features aren't needed; **Niagara remains the more feature-complete recommendation.**

**OWL 21 limitations:** No contact search, adjustable haptic strength, or Home/Back dismissal of alphabet browsing. OWL animations are capped at 60 FPS, even on 90/120 Hz displays; slower rendering can reduce this further. Higher-refresh animation requires an Omalauncher engine change.

**Switch back:** Samsung → Settings → Apps → Choose default apps → Home app → **Niagara Launcher**.
